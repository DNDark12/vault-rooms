# Vault Rooms 0.2.9

**Workflow:** bug-triage delivery. **Status:** release preparation; no tag or publication authorized by the branch-push request. Integrate develop into the existing main branch after branch CI passes.

## Release notes

This update protects sync data during deletion, mode changes and portable-name recovery, and makes paused files visible and actionable.

- Blob cleanup now persists the referencing database changes before deleting content. Failed persistence retains the blobs.
- Turning Live editing on or off coordinates seeding, pending saves and document retirement. Stale epochs cannot overwrite current files.
- Pinned HTTPS raw uploads send the expected byte-buffer type. Embedded requests authenticate before accepting large bodies, restrict CORS to Obsidian, and report background database-save failures with bounded retry.
- Blocked access denies all data permissions. Existing deny rules containing exactly the former reader permissions migrate to a full block; custom partial denies keep their scope.
- File identity uses NFC plus lowercase on every platform. New names reject Windows reserved names, punctuation and trailing spaces/dots. Legacy collisions are quarantined without merging, with stable-ID owner repair preserving history. Read ACLs use the same identity rules.
- Paused files have panel attention, an edit Notice and an explicit review/retry flow. Local aliases can be repaired by exact file/folder name after preserving files, CRDT state and pending intent.
- Recovery preserves edits arriving during downloads and refuses to overwrite a recreated local file. Pending CRDT saves, retirement and cache repair serialize across plugin reload; stale opens and queued renames cannot revive retired documents.
- Peer CRDT updates use the stored server path spelling. Rename fanout respects read access to each path and sends a full snapshot only for collision repair or required reconciliation.
- LAN discovery no longer reads OS network-interface inventory. Invalid UTF-8 in text files is rejected visibly and retained locally.
- An editor opening a case or Unicode-normalization alias no longer undoes a pending rename or reports a false different-file collision. Disk reassignment occurs only when the server assigns a different portable identity.
- Approved dependency updates: Fastify 5.12.5, fast-uri 3.1.8 and SDK/build Moment 2.31.0. Obsidian supplies Moment at runtime; the SDK override does not replace the app's copy.

## Upgrade notes

Back up the vault and plugin-private server data before upgrading a host. Update the host and clients together for portable-name recovery: older clients cannot subscribe to rooms containing collisions they can read. No file is auto-selected as a collision winner. The owner repairs server names in Manage; each device reviews retained local work under Review paused files.

Database migrations retain backup/audit information. Keep recovery copies until their contents have been reviewed. Do not downgrade a migrated relay database in place; restore a pre-upgrade backup together with its matching plugin build when testing a rollback.
